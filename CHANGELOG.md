## 0.1.0

The first release of Holm, a keyboard-first app for Markdown notes on Linux (x86_64).

- Your notes are plain `.md` files in a folder you choose.
- Markdown shows as styled text while you type.
- Link notes with `Ctrl+K`; each note shows its backlinks.
- Search all notes with `Ctrl+Shift+F`, open one by title with `Ctrl+Shift+O`.
- Holm saves as you type and never goes online.
- `Ctrl+?` lists every key.

Holm is early. It has no sync and no updater: to update, download the next
release. If something goes wrong, open an issue and attach
`~/.local/state/holm/holm.log`.
